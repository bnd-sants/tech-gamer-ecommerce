# PROJECT: Tech Gamer E-Commerce

A premium, customized gaming e-commerce web application rebuilt from scratch.

---

## 🚀 Project Overview
* **Repository:** `Baiano-Indiano/tech-gamer-ecommerce`
* **Current Framework:** Vue 3 + TypeScript + Vite + Vuetify 3 + Pinia
* **Design Philosophy:** Cyber-HUD Industrial (0px sharp corners, high-contrast neon borders, cyber scanline overlays, glowing text).
* **Strict Constraints:** **Purple Ban 🚫** (no purple/violet/indigo hex codes allowed in styling).

---

## 🎯 Milestones

### Milestone 1: Frontend Foundation (COMPLETED)
* **Goal:** Migrate React application to Vue 3, styling with customized Vuetify themes, routing with protected guards, and state management with Pinia.
* **Status:** Complete. Application builds successfully.

### Milestone 2: Payment Integration, Admin Dashboard, and Advanced Frontend (ACTIVE)
* **Goal:** Integrate payments, implement admin management screens, and refine advanced frontend elements.
* **Scope:**
  1. **Option B (Payments):** Integrate Mercado Pago payment APIs (Pix dynamic QR, credit card tokenization, bank slips).
  2. **Option C (Admin Dashboard):** Admin routes to list orders, alter order fulfillment status, edit catalogs, and adjust inventory levels.
  3. **Option D (Advanced Frontend):** Support `vue-i18n` localization (PT/EN), animated transition reveals, and dynamic SEO route metadata.

---

## 🔧 Technical Stack (Milestone 2 additions)
* **Localization:** `vue-i18n` (v9+)
* **Payments:** Mercado Pago SDK / Axios checkout endpoints
* **Security:** Admin-only route middleware guard checks
